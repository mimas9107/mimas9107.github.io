邊緣語音 + IoT 簡報

ESP-MIAO (邊緣語音助理與 IoT 控制系統)

成果： 實現從喚醒詞偵測到伺服器語意解析與 MQTT 裝置控制的完整語音鏈路。
核心技術架構：
  1. 即時音訊串流 — 避免連續記憶體申請導致 OOM
  2. JSON 協議 — 統一 WebSocket 訊息格式
  3. MQTT 發現機制 — IoT 裝置動態註冊與 LWT 離線狀態
  4. 視覺回饋 — 7 種眼部動畫即時回饋
  5. 雙核心分工 — ESP32 Core 0 處理音訊，Core 1 顯示動畫
LLM + Gemini API 儀表板

LINE智慧助理 (LLM: Gemini API 整合)

  • 成果： 優化 ChatSession 狀態管理，顯著降低 Token 消耗與對話延遲。
  • 技術： Python + Flask + LINE Messaging API + Google Gemini API。
LAN 控制器 + IoT 簡報

vacuumd (次世代掃地機器人 LAN 本地控制器)

  • 成果： 斷網下仍可透過內建網頁儀表板操作，並與 Home Assistant 無縫整合，實現高可靠度的本地智慧清潔管理。
  • 技術： Python + Pydantic + FastAPI + MQTT + dnsmasq，內建斷網容錯（Fake Cloud）、智慧排程防衝突與充電座看門狗。
  • 情境： Roborock / Xiaomi 掃地機過度依賴雲端，斷網即離線休眠無法控制，將控制權完全收回本地。
